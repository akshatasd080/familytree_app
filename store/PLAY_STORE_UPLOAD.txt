Family Tree — Play Store go-live checklist
==========================================

App ID (applicationId): com.imt.familytree_app
App name: Family Tree
Version: pubspec.yaml → 1.0.0+1   (bump +N for EVERY new Play upload)
Upload keystore: android/app/upload-keystore.jks
Key alias: upload
Passwords: android/key.properties   (NEVER commit / NEVER lose — backup offline)

------------------------------------------------
A) Before you upload (code)
------------------------------------------------
1. API must be HTTPS production:
   - lib/core/constants/api_constants.dart → Environment.prod
   - Or build with:
     flutter build appbundle --release --dart-define=API_BASE_URL=https://familytree.dhilwari.com/api

2. Privacy page live on web:
   - File: famliyTree_frontend/public/privacy.html
   - URL: https://familytree.dhilwari.com/privacy.html
   - Deploy frontend so this URL opens in a browser

3. Build the Android App Bundle (AAB):
   cd familytree_app
   flutter clean
   flutter pub get
   flutter build appbundle --release --dart-define=API_BASE_URL=https://familytree.dhilwari.com/api

4. Output file:
   build/app/outputs/bundle/release/app-release.aab

------------------------------------------------
B) Play Console setup
------------------------------------------------
1. Create developer account (one-time fee) if not done.
2. Create app → package name MUST be: com.imt.familytree_app
3. Dashboard → Testing / Production → Create release → upload AAB
4. Store listing — copy from store/listing/:
   - title.txt
   - short_description.txt
   - full_description.txt
   - icon: store/icon_512.png
   - feature graphic: store/feature_graphic.png
   - phone screenshots: store/screenshots/ (add ≥2 real captures)
5. App content:
   - Privacy policy URL: https://familytree.dhilwari.com/privacy.html
   - Data safety: follow store/listing/data_safety.txt
   - Content rating: follow store/listing/content_rating.txt
   - Target audience / news apps / ads declarations as prompted (Ads: No)
6. App access: if login required for review, add a demo account
7. Submit for review
